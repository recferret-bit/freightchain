# Statistics – detail

Moved verbatim out of `AGENTS.md`, which keeps the short rules that bite and points here (AGENTS.md + CLAUDE.md are loaded into every agent session and must stay under the size limit). Keep this file current like AGENTS.md ("Maps stay current").

- **Statistics** (`docs/statistics.md`): `stats.PlayerStats` + `stats.GlobalStats` are RUNNING TOTALS (rides, completed, seconds, metres, crashes vehicle / building, donations, paid lamports) written ONLY by `StatsService` with atomic increments – the rider's row first, the global row second – inside the transaction that saves an ended ride, from EVERY path that ends one (`/end`, a failing heartbeat, the stale sweeper, create / start clearing a stale ride; player row lock FIRST – the stats insert's FK check deadlocked with the sweep otherwise) and after a donation event is created (the DRIVER's row; lamports only when paid). `test/architecture/stats-hooks.spec.ts` guards it. Every STARTED ride that ended counts (the landing used to count only completed shifts: `0.00 km` on production). Crashes are client-reported running counts (`crashesVehicle` / `crashesBuilding` in heartbeat + `/end`, only raised, capped by driven time (3 + 1 per 3 s, ≤ 200), never judged; the game: `st.crashV` / `st.crashB`). Reads go through `StatsService` + `CachePort` (Redis when `REDIS_URL` is set – the prod compose `redis` service: `REDIS_PASSWORD` required in `deploy/.env`, no published port, `internal` `cache` network shared with the app only, never expose it –, else in-process; TTL 15 s, writes invalidate, a down Redis = a miss); `rides` = `ridesFree` + `ridesPaid` (tier `free` or not): `GET /api/stats`, `GET /api/stats/daily` (`stats.DailyStats`: the UTC day a ride ENDED / a donation landed – the THIRD upsert after rider and game; the newest 90 days), `GET /api/live` `totals`, `GET /api/profile` `career` (lobby DRIVING RECORD, `site/lobby-career.js`). Repair: CLI `stats:reconcile [--wallet] [--fix]` / skill `stats-reconcile` (production read-only unless the user asks). A change to what counts = the migration's backfill + `StatsPrismaRepository.recompute` + `rideDelta` together. E2E: `bash .claude/skills/run-tests/e2e.sh stats`.
