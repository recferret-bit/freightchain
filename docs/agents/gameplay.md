# Controls + gameplay systems

Agent reference, moved verbatim out of `AGENTS.md` (which keeps only the map and the hard rules and is loaded into every agent session); an "In short" block, where there is one, is a summary. Read the file for a topic before changing it; keep it current like AGENTS.md ("Maps stay current"). Paths are relative to `client/` unless they start with `server/`, `landing/` or `media/`.

## Controls

W/↑ gas · S/↓ brake · A D/←→ steer · **Shift/Space = clutch (hold)** · E/Q gear up/down (clutch must be in; 1–7 / 0 select gear/neutral; **Q from neutral or G = reverse**, stop first) ·
**B parking brake** (ON at the start of every ride – release it before moving; also the red PARK octagon on the dash; spring brake, `CFG.PARK_BRAKE` 9 m/s², works with the engine off and holds against thrust – the service brake pedal does NOTHING with the engine off/stalled). **Driving against a held brake** (`st.fight`: gear in, clutch out, gas on, truck pinned by the parking brake or pedal) heats the brakes (`FIGHT_HEAT`, BRAKES lamp; hot brakes fade, the parking brake too) and charges the STRAIN lamp over `FIGHT_TIME` s – full = the drivetrain gives out, ride over (`st.blownWhy = 'brakes'`). With the pedal the engine simply stalls (the slip hold rpm is cut by braking) · **I start engine** (also after a stall; **O** or click the key = engine off) · **H cab heater (HEAT button)** · **J cab cooling (COLD button)** — on a warm route the windscreen fogs while cooling is off; it draws the same battery current as the heater · **L headlights · C cab light** (or the HEAD / CAB dash buttons; the cab light is also the dome lamp in the overhead console and it works whenever the key is ON, cranking or running (`cabAllowed()` = `powered()` in sim/battery.js; it goes out with the key off); day/night also in the menu) · R wipers off/slow/fast · hold X washer spray (or click WIPER/WASH on the dash) · **T radio on/off · , . station · − = volume** (or the ‹ PWR › dash buttons; needs key ON) · **N phone map** (or click the phone on the dash; Escape / EXIT closes it; read-only) · P pause (→ END SHIFT) · M mute. Driving controls are desktop-only; mobile visitors are blocked from driving and guided to spectate live rides and replays.

### Gameplay systems
Tweaking these numbers — how the truck drives, how hard a failure is, how long a system lasts — is the `gameplay-balance` skill (`.claude/skills/gameplay-balance/SKILL.md`, `/gameplay-balance`). The check it runs is `cd client && npm run check`.
- **Road holes** (`net/obstacles.js` data + `world/holes.js` meshes, `CFG.HOLES / HOLE_CHANCE / HOLE_FIRST / HOLE_WARN`; online rides and replays use the SERVER's plan, see "Verified play"): five types in the `HOLES` table (pothole, deep, cluster of 3, trench = lane-wide, sinkhole = lane-wide + cones); each is a list of ellipses `{ds, dl, a, b}` (road coords) + `dmg / slow / jolt / kick / crawl`.
  Placement is a pure function of the chunk index and the seed's layout (`rollHole(ci)`: ≤ 1 per chunk, hash `rnd`; the server's `road-plan.ts` is the same function) so traffic can see holes in chunks that aren't built; `chunks.js` calls `buildHoles()` which draws the decals and a yellow warning sign (pictogram per type, `HOLE_WARN` m before the hole, lat 7.6, a destructible `KINDS.sign`).
  **Not colliders**: `hitHoles()` (`sim/damage.js`) tests each wheel (±1 m) of three axles (front / drive / trailer) against the ellipses once per ride → jolt, hull ∝ (v/28)², speed loss, steering pull; so a small pothole can be straddled. AI: `dodge()` in `sim/traffic.js` (stateless each step): shift inside the lane → other lane if `laneFree()` → crawl at `crawl` m/s; no weaving near holes. Add a type: a `HOLES` row (+ a `dips` entry for its sign pictogram in `signMat`, + mesh case in `makeHole` if it needs a custom look). Debug: `__game.holes`.
- **Traffic** (`sim/traffic.js`, `CFG.TRAFFIC*`, `CFG.CROSS_*`): vehicles are records in the coords of their `road` (`MAIN` or a crossroads' `net.lineOf(j)`): `s`, `lat`, `lane`; `dir` -1 = oncoming; lane i at `laneLat(dir, i)` (inner lanes ±2.4).
  Lights: red / amber-that-can-stop = an obstacle at the stop line; green waits while the box is occupied. Lane ends ahead → merge left or wait. Overtaking: next lane left on multi-lane roads, the oncoming lane on 1+1 (never towards a junction). Type = `VEHICLES` (sedan, truck, bus, freighter, police, medic, fire),
  behaviour = `PRESETS` (cruise, slow, tailgate, overtake, weave, emergency). Add a type: a vehicle entity (`client/shared/entity/seed/vehicle/<type>.js`) + a `VEHICLES` row in `client/shared/traffic.js` + a `ROSTER.vehicle` row; add a behaviour: a `PRESETS` row (+ the type's `presets` weights).
  Contact (`contact()`): nose engaged ≥ `CRASH_OVERLAP` of the width and closing ≥ `CRASH_CLOSING` = **direct hit → ride over** (reason string returned to `physics.js`, which calls `endRide` before the hull check);
  slower nose contact or a hit on the trailer = bump (hull damage); alongside / corner clip = scratch (`SCRATCH_DMG`). The truck is TWO boxes, cab and trailer, in road axes, stretched by `CFG.TRAFFIC_DRIFT` s of its sideways drift (`partBox` / `truckBox` / `reach`). Touches by the SAME car less than `TRAFFIC_RUB_GAP` s apart are ONE crash (`st.crashV` once; a re-hit costs only what it adds over that crash's worst). The AI keeps `TRAFFIC_CLEAR` m of side gap from the truck (it follows instead of squeezing past), moves away from a truck coming at it (`evade`), never pulls out to overtake – or pulls back in – when the truck is in (or within `TRAFFIC_LOOK` / 2 s of) that lane, and brakes for the truck turning out of the depot. Vehicle–vehicle contact is avoided by the AI, not simulated (a shoved car is only a wall for the one behind it). **Weight**: a touch is a momentum exchange along the contact normal (`exchange()`: `CFG.CRASH_TRUCK_MASS` vs the type's `mass`, restitution `CRASH_BOUNCE` on the first touch only, 0 while pushing) – the rig shoves a sedan along, a freighter stops it; the truck only ever LOSES speed from it (verdict: no speed gained without gas); overlap is split by weight. **State machine** (`a.state`, `limp()` / `settle()` in `sim/traffic.js`): `drive` → `crashed` (stunned `CAR_STUN` s, wheels drag `CRASH_FRICTION`) → front free (`CAR_FREE_GAP`) ? `drive` : room behind ? `back` (reverse ≤ `CAR_REVERSE_MAX` until `CAR_BACK_GAP` free, then `hold` until the road is clear) : `honk` (hazards + horn). Any stopped car with the truck in front for `CAR_BLOCK_T` s takes the same path. Cars behind a non-`drive` one (`a.wait`) never change lane / overtake; a queue whose head backs into it backs with it (`yield`). Hazards = both indicators; replays don't show them (snapshot flags unchanged). The `level-check` skill drives the free levels against it.
  Debug: `__game.spawn(type, preset, zone 'ahead'|'behind'|'oncoming', dist, lat)`, `__game.traffic`. Own seeded PRNG, drawn from the road seed (`resetTraffic(seed)` in `roads.newTrip` – riders on one shared seed start among the same cars; the damaged truck's pull side comes from the seed too), but still floats + variable `dt` – not replayable. `TRAFFIC:false` leaves the headless trace identical to pre-traffic.
- **Reverse** (`st.gear = -1`, `REV_RATIO`, `CFG.REVERSE_MAX` 6 m/s): `st.v` stays the speed (≥ 0); `st.rev` = moving backwards, `st.vel` = signed velocity (use it where direction matters: position, heading, traffic closing speed). Forward↔reverse needs `v < .8` (else GRIND). Reversing swings the trailer out (`tyaw` clamped ±1.2 rad), beeps (`audio.beep`), lights the trailer's white reverse lamps. **Gaps**: reversing ignores roadside props (`collide()` returns early; the trailer has no scenery collision), and `s` is clamped at the start line.
- **Ignition key** (OFF/ON/START zones on the dash, `ignitionPanel()` in `cockpit/common.js`; `keySwitch/ignition(true)/releaseKey/engineOff` in `sim/physics.js`): `powered()` (state.js) = engine on or `st.keyOn` or cranking; with the key OFF all gauges (`updateDisp`), lamps, gear display, trip LCD and LED bars are dead; turning to ON runs a 1 s self-test sweep (`st.test`). Engine off: air is frozen; engine temp cools slowly towards ambient (see "Climate"). START is hold-to-crank (~1 s) with the mouse; `I` is a one-tap auto start.
- **Gearbox** (`RATIOS` in state.js, torque curve `CFG.TORQUE_*`, `GEAR_EXP` in the F2 panel): 7 gears, geometric ×1.42, ratio 6.15 → 0.75 (8.2:1). Useful range at 1000–2500 rpm, km/h: 1st 5–14 · 2nd 7–20 · 3rd 10–28 · 4th 14–40 · 5th 20–57 · 6th 28–80 · 7th 40–100. Thrust ∝ (ratio/1st)^`GEAR_EXP` (.4; 1st gear's thrust is fixed, a bigger exponent only weakens taller gears) × torque(rpm); engine braking ∝ ratio^.4; torque is a parabola peaking at `TORQUE_PEAK` 2000 rpm (width `TORQUE_LOW_W` 800 below, `TORQUE_HIGH_W` 1500 above) and ~0 around 1200 – so 30 km/h in 5th–7th lugs or barely pulls, 4th is the gear for it, so a tall gear at a crawl lugs and stalls instead of pulling (standing starts: 1st/2nd fine, 3rd/4th can't move off, 5th+ stalls). Holding the redline in a low gear charges max-rev strain – shift up. The headless test's scripted driver upshifts at 2300 rpm for the same reason.
- **Battery** (`sim/battery.js`, `CFG.BATT`, `st.batt` 0..1, BAT lamp + VOLT gauge): drained per second by the headlights (.0025), cab lamp (.0015, works with the key ON), heater blower (.005), cooler blower (.005, the same current), radio (.001), key-on instruments (engine off, .0008) and the starter (.06 while cranking ≈ −.085 per start); with the engine OFF every consumer drains `OFF_X` (2.5)× faster; refilled by the alternator only while the engine runs (`CHARGE_MIN` .004 at idle … `+CHARGE_RPM` .003 at redline, tapering above ~75 %; HEAD + HEAT and HEAD + COLD, and so HEAD + CAB + HEAT, always out-drain it – `client/test/battery.test.mjs` pins that). **Resource rules**: engine off with no lights / heater / cooler / radio (key ON or OFF) heals `REST` .008/s up to `REST_MAX` .5; below `CRITICAL` .2 with the engine off = alarm + toast; `ignition()` refuses below `START_MIN` .12 (a crank costs ≈ .085, so a start never ends below `DEAD`); **flat (≤ `DEAD` .01) is never a dead end**: `st.battDead` cuts lights, radio, heater and cooling, the rest recovery then brings the charge back above `START_MIN` in about a minute (the old `battLost` ride-over is gone). BAT lamp amber below `LOW` .3, red + blinking below .15. All rates are test-scale (5 min ride).
- **Engine**: `st.ign` is the start sequence (0–1 s key-on gauge sweep + bulb check, 1–2.3 s cranking, then the engine catches with a rev flare and rumble).
  Stall = gear engaged, clutch mostly out (>0.55 engagement) and rpm < 450 for 0.12 s. **Clutch slip** (`st.slip`, armed by clutch in / neutral): until the wheels catch up with the engine (lock-up), rpm isn't dragged down to wheel speed but held at `360 + TRUCK.LAUNCH_RPM·gas` (× power factor, less in 3rd+, 0 while braking) – without it the 0.6 s clutch release stalls every launch at `MASS 2.5`. After lock-up rpm = wheel speed again (stopping in gear stalls). Launch checks at the end of `tools/headless-test.mjs`. Gauges read the sprung `disp.*` values, not `st` directly.
- **Damage**: props are registered as colliders in `chunk.userData.colliders` (`KINDS` table: `hp` is a speed² budget, `dmg` = hull % lost in a 28 m/s hit,
  `slow` = speed fraction lost when it breaks). Unbroken props bounce the truck. Smashed props are remembered in `destroyed` so a rebuilt chunk doesn't resurrect
  them; `resetRide()` clears that set and all chunks. Hull < 100 % cuts engine power (down to 40 %) and adds a steering pull (random side per ride); 0 % ends the ride.
  Colliders may be long and thin (`rf` along / `rl` across the road in `KINDS`, e.g. guardrails, which fall outward when broken). Not colliding: the trailer, the mountains, the road.
- **Windscreen**: dust lives on a 512×256 offscreen "grime" canvas stretched over the top 65 % of the screen. Wiper blades erase the swept triangle; dry blades only
  clear ~25 % per pass. While the glass is wet (washer), every pass also clears ~45 % of the whole screen (`washAll`). Wipers only reach the left/centre of the glass.
- The washer tank (`st.wash`) is finite: it drains while spraying (`CFG.WASH_DRAIN` 0.01 = 100 s of spray per ride) and never refills; a small H2O gauge shows it (semi cockpit only).
- Exhaust smoke (`drawExhaust`) only exists in the semi cockpit.
