- **Split hosts in production**: landing + lobby on the apex, the game on `ride.<apex>`, the API on `api.<apex>`, the model viewer (`client/viewer.html`, nginx maps `/` to it; no API there) on `storybook.<apex>`, the whitepaper (`landing/whitepaper.html`, nginx maps `/` to it and 404s `/api/`; the page posts web vitals to `api.<apex>`) on `whitepaper.<apex>`, the pitch deck (`landing/pitchdeck.html`, nginx maps `/` to it and 404s `/api/`; its one request is anonymous analytics to `api.<apex>` (no credentials; in `CORS_ORIGINS` for that), noindex, its own web manifest; the landing footer links it through `PITCHDECK_BASE`) on `pitchdeck.<apex>`, the admin page on `admin.<apex>` (nginx basic auth; its API calls stay on that host – `ADMIN_BASE`) (nginx on the box, `deploy/`). For search each page has ONE public URL (its `<link rel="canonical">`): nginx 301s `ride.<apex>/` to the apex, `<apex>/whitepaper.html` to `whitepaper.<apex>/`, `<apex>/pitchdeck.html` to `pitchdeck.<apex>/` and `www.<apex>` to the apex – see `docs/agents/landing.md` "Search + AI crawlers". All client API calls go through `client/js/hosts.js` (`API_BASE` / `GAME_BASE` / `SITE_BASE` / `STORYBOOK_BASE` / `WHITEPAPER_BASE` / `PITCHDECK_BASE` / `ADMIN_BASE`, `''` on localhost / IP / `file://`) with `credentials: 'include'`; the server needs `COOKIE_DOMAIN` + `CORS_ORIGINS` (derived by the deploy). New fetches/links to the game or lobby must use those bases, never a bare `/api/…` or `/play.html`.
- `npm run server:dev` (root) starts Nest on :3000, which also serves `client/` – the page and `/api` share an origin, so the session cookie needs no CORS. `client/serve.sh` still serves the game alone (offline mode).
- **Online mode is opt-in**: `play.html?ride=<id>` (`js/online.js`) takes the seed + shift length from the server and heartbeats it. every other `play.html` (bare, `?offline=1`) is the uncounted guest free run (the EASY level's road, trip `free-1`; tutorial / assist picked in its menu, no requests; `?watch=` is the spectator). Tools that want the plain sim call `__game.devRun(tripId = '1h')` after boot (classic road, no helpers); there is no `?trip=` / `?tutorial=` URL any more.

- **Logs**: `JsonLogger` – one JSON object per line in production (`{time, level, context, msg, …}`), a line per API request (`event:'request'`, status, ms, requestId, wallet, ip), events `signin` / `admin-signin` / `verdict` / `admin` / `batch-refused` / `telemetry-sweep`; the last 5000 also in memory for the admin page. Time from `ClockPort`.
