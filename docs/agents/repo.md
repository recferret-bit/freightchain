- **Split hosts in production**: landing + lobby on the apex, the game on `ride.<apex>`, the API on `api.<apex>`, the model viewer (`client/viewer.html`, nginx maps `/` to it; of the API only `/api/entities/` (the public 3D model bundle) and `/api/editor/` (the model editor, `EDITOR_WALLETS` only, same-origin – `docs/spec/platform_services.md`) are proxied there, every other `/api/` path 404s) on `storybook.<apex>`, the whitepaper (`landing/whitepaper.html`, nginx maps `/` to it and 404s `/api/`; the page posts web vitals to `api.<apex>`) on `whitepaper.<apex>`, the pitch deck (`landing/pitchdeck.html`, nginx maps `/` to it and 404s `/api/`; its one request is anonymous analytics to `api.<apex>` (no credentials; in `CORS_ORIGINS` for that), noindex, its own web manifest; the landing pitch-deck band and the footer link it through `PITCHDECK_BASE`) on `pitchdeck.<apex>`, the admin page on `admin.<apex>` (nginx basic auth; its API calls stay on that host – `ADMIN_BASE`) (nginx on the box, `deploy/`). The same names on this machine are `http://freightchain.localhost` (`npm run infra:local`; `deploy/local/dev.env` sets `COOKIE_DOMAIN`). For search each page has ONE public URL (its `<link rel="canonical">`): nginx 301s `ride.<apex>/` to the apex, `<apex>/whitepaper.html` to `whitepaper.<apex>/`, `<apex>/pitchdeck.html` to `pitchdeck.<apex>/` and `www.<apex>` to the apex – see `docs/agents/landing.md` "Search + AI crawlers". All client API calls go through `client/js/hosts.js` (`API_BASE` / `GAME_BASE` / `SITE_BASE` / `STORYBOOK_BASE` / `WHITEPAPER_BASE` / `PITCHDECK_BASE` / `ADMIN_BASE`, `''` on a bare localhost / IP / `file://`) with `credentials: 'include'`; the server needs `COOKIE_DOMAIN` + `CORS_ORIGINS` (derived by the deploy, or `deploy/local/dev.env` locally). New fetches/links to the game or lobby must use those bases, never a bare `/api/…` or `/play.html`.
- `npm run server:dev` (root) starts Nest on :3000 and sources `deploy/local/dev.env` first (existing env wins over `server/.env`). The browser uses the local edge; bare `localhost:3000` is still one origin. `client/serve.sh` still serves the game alone (offline mode).
- **Online mode**: `play.html?ride=<id>` (`js/online.js`) takes the seed + shift length from the server and heartbeats it. Bare `play.html` orders the real EASY ride (`js/easy-entry.js`: `POST /api/auth/guest` when nobody is signed in, then `POST /api/rides` level 1). `?watch=` is the spectator. `?sim=1` is the local tool sim (`free-g`); tools then call `__game.devRun(tripId = '1h')`. There is no `?trip=` / `?tutorial=` / `?offline=1` product URL any more.

- **Logs**: `JsonLogger` – one JSON object per line in production (`{time, level, context, msg, …}`), a line per API request (`event:'request'`, status, ms, requestId, wallet, ip), events `signin` / `admin-signin` / `verdict` / `admin` / `batch-refused` / `telemetry-sweep`; the last 5000 also in memory for the admin page. Time from `ClockPort`.
