# Promo videos + sound – detail

Agent reference, moved verbatim out of `AGENTS.md` (which keeps only the map and the hard rules and is loaded into every agent session); an "In short" block, where there is one, is a summary. Read the file for a topic before changing it; keep it current like AGENTS.md ("Maps stay current").

## In short

Skills `gameplay-video` / `game-audio`. `node media/make.mjs media/specs/<name>.json` (root `npm run media -- …`) turns a spec into `media/out/video/<name>/`: mp4 ≤ 15 s (with an 8-bit soundtrack when the spec has `audio`) + gif ≤ 20 MB + `contact.jpg` + `timeline.json` + `.min.mp4` / `.min.gif` / ≤ 500 kB `.tiny.gif`; real gameplay in headless Chrome on a **virtual clock** (deterministic). **Generated clips and their sound are NOT committed** (gitignored; only `media/out/video/intro/intro.mp4`, which the README links, and the sound store are – re-render with the spec); the sound store is `media/out/audio/_store/` (`npm run media:store`); the game's own sfx are built by `npm run media:game-sfx` → `client/audio/sfx/`. Needs **a real GPU** (software GL z-fights the road ribbon against the ground – the asphalt flashes). **Depends on game internals** (`window.__game`, `tryShift` + the clutch rules, RATIOS / `K_RPM` mirrored in `media/video/page.js`): after changing those run `npm --prefix media run preview` and look at `contact.jpg`. **TikTok clips** (`crop: "vertical"` = `look: "meme"`, 1080×1920, 30 fps, `media/specs/tiktok-*.json`; `--preview` keeps the layout at half the pixels): the game still runs at 1280×720 inside a 1080² window (`window.innerWidth/Height/devicePixelRatio` are overridden in `capture.mjs`), impact-font captions + an LCD clock sit in the bands (TikTok's own UI covers the top ~170 px, the bottom ~320 px and the right edge – keep text out). **Copy**: stay with what the landing says (devnet, one weekly SOL pool, 30-minute shifts); no payout amounts, no mainnet or guarantee claims. `npm --prefix media run lint|test` are in `npm run check`.

## Detail

`node media/make.mjs media/specs/<name>.json` (root: `npm run media -- media/specs/intro.json`; flags `--preview` half-size/12 fps, `--only a-b` a time range, `--keep` the JPEG frames, `--video-only`, `--audio-only` = the WAVs + cue sheet only (no capture, no video needed), `--remux` = rebuild the sound from the saved `timeline.json` and put it on the existing mp4, `--add-audio file.mp4 [--out x.mp4]` = sound for ANY mp4 (a spec with only an `audio` block is enough; the original is never overwritten), `--compress`; one mode per run) turns a JSON spec into `media/out/video/<name>/<name>.mp4` (≤ `maxSeconds`, 15; **with sound when the spec has an `audio` block**) + `.gif` (silent, ≤ `gif.maxMB`, 20; shrinks then trims to fit) + `contact.jpg` + `timeline.json` (what really happened in the footage: every gear shift, the crash, rpm per frame – the sound is synced to it), plus compressed look-alike copies `<name>.min.mp4` (crf 24, keeps the audio) + `<name>.min.gif` (128 colours, ≈ 80 %) + `<name>.tiny.gif` (whole clip ≤ 500 kB) made from the finished originals. `look: "big"` + `crop: "square"` = no small text, one huge word per scene, centre square crop (`media/out/video/intro-square/`, silent). Scene `shots[]` = a collage of framed screenshots (from `media/assets/`, served at `/__assets/`) and stat cards over the blurred road (`bg: "sol"` adds the Solana glow): `media/out/video/colosseum/` is the 59 s Colosseum progress clip (game, lobby, live watch + CB chat, recorded rides, the escrow program, the localnet test, admin, whitepaper); a clip over 20 s gets no `.tiny.gif` and its music repeats the score. **Generated clips are not committed** (only `media/out/video/intro/intro.mp4` is, for the README). **Sound**: `media/audio/` is a pure-JS chip synth (Master System / Mega Drive voices – pulse with duty cycles, triangle, LFSR noise, 2-op FM; the same family as the cab radio's PIXEL RALLY station), seeded so a re-render gives the same WAVs; `sfx.mjs` = the recipes (ignition 0.5–0.9 s, shift, crash, game-over, a sound per transition type, caption beeps, dash clicks, wiper, washer, end card), `scores/` + `music.mjs` = the music (tempo is fitted so 8 bars end with the clip), `cues.mjs` = what plays when (from the spec + `timeline.json`), `mix.mjs` = engine bed from the recorded rpm + ducking + master. `media/out/audio/_store/` (+ `manifest.json`) is the reusable library, rendered by `npm run media:store`. **The game's own effects** are a third output of the same synth: `npm run media:game-sfx` → `client/audio/sfx/<id>.<hash>.mp3` + `manifest.json` (committed; see `js/sim/audio.js` in the layout). Serving: the app sends them `immutable` (`static-cache.ts`), nginx caches them in the `fc_media` zone (`/etc/nginx/snippets/freightchain-media.conf`, marker `fc-audio`; `deploy` re-runs setup while the marker is missing) and the deploy smoke checks manifest + mp3 + `X-Cache: HIT`. **Vertical / meme vocabulary** (`video/page.js` `buildMeme()` / `drawMeme()`): caption `{at, dur, head, fx: slam|type|words|shake|glitch|bubble|stamp, pos: top|mid|low or x/y, color, size, rot, cps, per}` (`bubble` = a comment reply: first line is the username); scene `clock {from, to, fmt: hms|ms, label, of, color, ease}` (an LCD counter – the time-lapse is faked as a pure function of the video time, never simulated), `lines` (speed lines, 0–1 or [a, b]), `shake` (px rumble), `cam {z, x, y}` (zoom / pan on a game pixel; scalars or [from, to]), `band` (CSS colour of the bands), `beat` (pulse on the music's beat, `false` off, a number scales it; `make.mjs` sets `spec.beat` from the score's fitted tempo); transitions `punch` and `spin`. Sounds `boom scratch airhorn bruh ding levelup riser wah tock` + scores `bus-stop brainrot uneasy` are in the store. Workflow, spec vocabulary and copy rules: `.claude/skills/gameplay-video/SKILL.md` (clips) and `.claude/skills/game-audio/SKILL.md` (sounds, scores, the store).
- **How it works**: `media/video/capture.mjs` serves `client/`, boots `play.html` in headless Chrome and installs a **virtual clock** (`media/video/clock.js`: fake `performance.now`/`Date.now`, queued `requestAnimationFrame`, seeded `Math.random`) – one video frame = one exact game step, so a render is deterministic (a fresh checkout reproduces the committed mp4/gif byte for byte). `media/video/page.js` runs inside the page: the *director* sets each scene up through `window.__game` (route, time, cold engine, pre-roll) and drives it with a per-step hook (scripted speed, auto-upshifts with real clutch dips, lights / wipers / washer / traffic events), the *fx* layer draws the landing-styled overlay (ticker, route chip, Solana badge, typewriter captions, transitions, crash stamp, end card) as a pure function of the video time – never CSS animations or timers. `media/video/encode.mjs` = ffmpeg (npm `ffmpeg-static`, no system install).
- **Needs**: Node ≥ 22, Chrome (`CHROME=…`), `npm --prefix media install` (ffmpeg-static downloads its binary), and **a real GPU** – software GL (SwiftShader) z-fights the road ribbon against the ground, so the asphalt flashes; `GPU=0` forces it (only for quick looks). `PORT` = Chrome debug port (default 9555).
- **Depends on game internals**: `window.__game`, `st`/`dn`/`input`/`weather`, `tryShift` + the clutch rules in `sim/physics.js` (`input.clutch` is boolean, `shiftT` holds the clutch ≥ .9), the RATIOS / `K_RPM` mirrored in `media/video/page.js`. After changing those, run `npm --prefix media run preview` and look at `media/out/video/intro-preview/contact.jpg`; after changing cockpit / world visuals re-render the intro and commit the new clips if the look changed.
- **Copy**: stay with what the landing says (devnet, one weekly SOL pool, 30-minute shifts); no payout amounts, no mainnet or guarantee claims.
- Lint + tests: `npm --prefix media run lint` and `npm --prefix media test` (both in `npm run check`; the tests need no Chrome: audio determinism / spec / cues / mix, the committed sound store byte for byte, and every `make.mjs` mode on real ffmpeg). The capture is deterministic per machine + game code, not forever: a clip committed earlier can differ from today's render (the game moved on) – re-render, compare `contact.jpg`, and say so.
