# Free run levels, helpers, free rides – detail

Agent reference, moved verbatim out of `AGENTS.md` (which keeps only the map and the hard rules and is loaded into every agent session); an "In short" block, where there is one, is a summary. Read the file for a topic before changing it; keep it current like AGENTS.md ("Maps stay current").

## In short

- **The free run – three LEVELS** (`server/src/domain/rides/ride-trip.ts` `FREE_LEVELS`): `POST /api/rides` `level?: 1|2|3` (default 1; a level on a paid tier 409 `level_free_only`): **1 EASY** `free-1` 60 s / 420 m (four lanes, no junctions) · **2 CROSSROADS** `free-2` 180 s / 1512 m (junctions, a fork) · **3 HARD** `free-3` 600 s / 6720 m (full network, NO assist and NO tutorial – 409 `assist_not_allowed` / `tutorial_not_allowed`, the game forces both off). Each level is one hardcoded country (EASY Australia · Stuart Highway `stuart`, CROSSROADS USA · Route 66 `route66`, HARD Austria · Italy · Brenner Pass `brenner` – `client/js/free-countries.js`); the server stamps that route and re-choosing the level moves it. Shift = `FREE_RIDE_SECONDS` × 1 / 3 / 10. A free ride ENDS BY ITSELF at the line. Ordering again re-chooses the READY free ride in place without a credit (`readyFreeRide` in `/api/me`; `/start` refuses a re-chosen one, 409 `ride_rechosen`). One free leaderboard per level. Achievements `free-easy` / `free-crossroads` / `free-hard`. **Trips**: the server stamps `Ride.trip` on every ride so a replay rebuilds the same road; a trip id is FROZEN once rides carry it – retune with a new id (`client/js/trips.js`); `holesFrom` and `road` are JUDGED and mirrored in `road-rules.ts` (`TRIP_HOLE_FIRST` / `TRIP_ROADS`). Skills `trip-design`, `level-check`.
- **Free-ride helpers – TUTORIAL + ASSIST** (free tier only, the lobby's two checkboxes, `Ride.tutorial` / `Ride.assist`; a paid tier refuses either with 409): tutorial = `ui/tutorial.js` (each step waits for the driver; negative cases in `trouble()` – add one when players get stuck; nothing may flash), starting a ride with it on sets `Player.tutorialPassedAt`; assist = `ui/assist.js`, hull damage + battery drain ×`CFG.ASSIST` 0.5 + tips; the server mirror `ASSIST_HULL_DAMAGE` must stay above the verdict's `PASS_DAMAGE_SHARE` (`world-checks.spec.ts`). Both draw through the LEAF `js/guide.js` → `cockpit/guide.js` (never in replays); off they change nothing (`npm run trace:diff` identical). Achievement `on-my-own`. `play.html?offline=1` forces both off.
- **Free rides**: a new wallet starts at `free_on_signup` (10); the daily +1 refill at 00:00 UTC stops at `free_rides_daily_max` (5) and never takes a surplus away; both are rows in `player.GameSetting`, changed with the signed admin settings API (which can also add / remove one wallet's balance). `play.html?offline=1` = the guest free trip (EASY road, in that level's country; tutorial / assist from its menu; nothing counted or recorded); bare `play.html` stays the prototype.

## Detail

- **The free run – three LEVELS**: a free ride is ordered at a LEVEL (`POST /api/rides` `level?: 1|2|3`, default 1, anything else 400; a level on a paid tier is 409 `level_free_only`; asking again re-chooses the READY free ride's level + helpers on the same ride id – without a `level` it keeps the ride's own; the game's `POST /api/rides/:id/start` sends the `trip` it built its road from and a ride re-chosen since is refused, 409 `ride_rechosen`, the game reloads), each its own trip, shift and finish line (`server/src/domain/rides/ride-trip.ts` `FREE_LEVELS`: shift = `FREE_RIDE_SECONDS` (60) × its multiple, finish = K × 28 m/s × that; paid stay K 0.5): **1 EASY** (`free-1`, × 1 = 60 s, K 0.25 → 420 m: four lanes – pattern `dual`, no junctions –, the straight start, gentle bends, no sinkhole within reach – holes from 1200 m) · **2 CROSSROADS** (`free-2`, × 3 = 180 s, K 0.3 → 1512 m: the depot STOP line + right turn, junctions – country / arterial / town –, a FORK right after the first stretch, hole chance × 1.5, holes from 400 m) · **3 HARD** (`free-3`, × 10 = 600 s, K 0.4 → 6720 m: the full network incl. highway, forks, bends × 1.3, traffic × 1.4, hole chance × 2, and NO ASSIST – the server refuses it, 409 `assist_not_allowed`, the game forces it off). `GET /api/tiers`' free row lists `levels: [{level, trip, name, seconds, completeDist, assist}]`; `RideDto.level` / `WatchRideDto.level` (null = a paid ride, or one on the old `free` trip). The lobby's level picker remembers the pick (`localStorage` `freightchain.level`). Each level chip shows that level's country, road and a short description, plus its time and distance (HARD: `10:00 · ≥ 6.72 km`); nothing under the picker repeats the time. The country is hardcoded (`client/js/free-countries.js`) and is the route the server stamps (`FREE_LEVELS.route`), so the drive is that country. The start hour still comes from the seed. Paid rides still take route and hour from the seed (`worldFor`). TUTORIAL and ASSIST are disabled on HARD (each block stays readable, crossed by a stop-sign banner). Achievements `free-easy` Learner's Permit ①, `free-crossroads` Crossroads ②, `free-hard` Long Haul ③ (`Facts.completedFreeLevels`). New free rides default to level 1 (`TRIP_OF_TIER.free = 'free-1'`); the old `free` trip (one minute, the straight start on the default layout) stays frozen for the rides that carry it. **Trips**: the server stamps the trip id on every new ride (`Ride.trip`, in the ride + watch payloads; null = a ride from before trips = 'classic') so a replay rebuilds the road the driver had: a trip id is FROZEN once rides carry it, retune with a new id (`client/js/trips.js`: `start: 'straight'` – the depot road runs straight on into the main road, no STOP line, no right turn, no traffic coming down it; the bends fade in over 150 m after it –, bends, traffic, calm cars, cross traffic, roadside density – client-only levers –, and two JUDGED knobs mirrored by the server: `holesFrom` (`road-rules.ts` `TRIP_HOLE_FIRST`) and `road` = the layout – `first` patterns, pattern `weights`, × `holeChance` (`TRIP_ROADS` / `tripRoadOf`; `new RoadLayout(seed, trip)`, `roadPlanFor(seed, ride.trip)`, drift-tested per trip); the old trips – classic / free / 1h / 4h / 8h, paid included – keep the default layout, unchanged) and a free ride ENDS BY ITSELF at the line with the green win stamp (`winFx`, `ui/fail-fx.js`). The free leaderboard is ONE PER LEVEL (`GET /api/leaderboard?board=free&level=1|2|3`, no level = 3 HARD, a level on a paid board = 400; index `Ride (status, trip)`): it ranks the completed free rides on that level's trip – the old `free` trip and classic rides rank on none; the lobby's FREE RIDES board has EASY / CROSSROADS / HARD under it (HARD by default, the pick in `localStorage` `freightchain.board-level`). A READY free ride (ordered, not started – its credit already spent) is `readyFreeRide { id, level, trip, tutorial, assist }` in `/api/me` (and the sign-in profile): the lobby keeps START on at 0 credits (`START FREE RIDE · ready`, its level + checkboxes preselected) and ordering again hands back that same ride, re-chosen, without a credit. Paid trips start at the depot's STOP line with the right turn and get harder 1 h → 4 h → 8 h (bends × 1 / 1.2 / 1.4, traffic × 1 / 1.4 / 1.8). Tuning: the `trip-design` skill.
- **Free-ride helpers – TUTORIAL + ASSIST** (free tier only; the lobby's free card has two checkboxes, `POST /api/rides {tier:'free', tutorial, assist}`; a paid tier refuses either with 409): stored on the ride (`Ride.tutorial` / `Ride.assist`, in `RideDto` – the game reads them from `GET /api/rides/:id`; offline `play.html?tutorial=1&assist=1`), a ready free ride is re-chosen in place when the lobby asks again. **Tutorial** = a dialog over the gameplay (`client/js/ui/tutorial.js`: ignition · parking brake · 1st gear + clutch · moving off · shifting up · steering · lights + windscreen · hull + crashes; each step waits for the driver to DO it, SKIP / END TUTORIAL; while it is open `guide.hold` keeps the free run's finish line from ending the ride). The tutorial also has NEGATIVE CASES (`trouble()` in `ui/tutorial.js`: stall, grinding, neutral, redline, lugging, off-road, parking brake on, low battery, damage): the dialog turns amber with what happened + the next actions and highlights the fix; add a case there when players get stuck. Success is cheered too: a green windscreen banner (`cheer()` in `guide.js`, drawn by `cockpit/guide.js`) on each finished step, small wins (steered both ways, lights, wipers) and a recovered stall. Pacing is constants at the top of that file (`MIN_STEP` 3 s, `DONE_MS` 2.2 s, `WARN_AFTER` / `WARN_HOLD` / `WARN_GONE`) – nothing may flash. **Starting a ride with the tutorial on** sets `Player.tutorialPassedAt` (first time only, in `StartRideHandler` under the player lock; `tutorialPassed` in `/api/me`) – the lobby's TUTORIAL box is then off by default. **Assist** (`ui/assist.js`): hull damage and battery drain ×`CFG.ASSIST` 0.5 (= twice the durability; `hurt()`, cold wear, `updateBattery` – fatal hits stay fatal) and a tip on every control / indicator when it matters (parking brake, gear up / down, stall, lights at night, low battery, hull…). The assist checkbox is remembered in `localStorage` `freightchain.assist` (the tutorial default comes from the server). Assisted free rides rank on their level's free board like any other. Both draw highlights through `client/js/guide.js` (a LEAF: `guide.tips` + the per-frame `guide.rects` the dash fills in beside `uiBtns`) → `cockpit/guide.js` (green frames + tip bubbles; replays and `st.watch` never draw them). Achievement **On My Own** (`on-my-own`): a COMPLETED free ride driven without assist. The server mirrors the factor (`ASSIST_HULL_DAMAGE`, `ride-rules.ts`) and must keep `PASS_DAMAGE_SHARE` (verdict) below it – `world-checks.spec.ts` pins both and drift-tests the client's constant; changing either number means re-checking the obstacle verdict. Tests: `guide.scenarios.ts`, the headless checks (`tools/headless-test.mjs`), `e2e-lobby.mjs`.
- **Free rides**: a new wallet starts with `free_on_signup` (default 10, `player.GameSetting` – existing wallets are not topped up). The daily refill is +1 at 00:00 UTC and stops at `free_rides_daily_max` (default 5): the midnight job (`DailyFreeRideScheduler` → `GrantDailyFreeRidesCommand` → one `UPDATE` in `PlayerRepositoryPort.grantDailyFreeRides`, also on boot) and the lazy `PlayerSessionService.touch` add only while `freeRides` is under that cap and never take a surplus away. The live cap is written onto `Player.freeRidesMax`. A promo or a signed admin grant may sit above it. A refund of an unstarted free ride adds one unless the balance is exactly at the cap. `/api/me` + `/api/profile` return `freeRidesMax` and `nextFreeRideAt` (epoch ms of the next 00:00 UTC, `null` at or above the cap) – the lobby chip shows `balance/cap`. Signed admin: `POST /api/admin/players/free-rides` adds or removes one existing wallet's balance (below 0 or above 100_000 is refused) and `POST /api/admin/settings` changes the knobs. **Guest runs** (`play.html?offline=1`): no wallet, no request, nothing counted, recorded or judged. The menu offers TUTORIAL (default on, `freightchain.guest-tutorial`) and ASSIST (`freightchain.assist`) and the run is the EASY road (`free-1`) in that level's country (Stuart Highway); a signed-in visitor plays it too. Offline rides are unrestricted: no fingerprinting, counting or limits.
