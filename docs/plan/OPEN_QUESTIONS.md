## Проверено 17.10.2026 (раунд 11, бывшие п. 4–9)

4. ✅/⚠️ **World ID 4.0.** Есть только разовая плата за регистрацию RP (ERC-20); плата за запрос — возможно в 4.1/4.2; модель «за активного пользователя в месяц» — намерение World. **Суммы не опубликованы** — узнать в Developer Portal при регистрации. 5. ✅ **Цены X API** (для сравнения): Post read $0.005, User read $0.010, Followers read $0.010, owned reads $0.001, потолок 3M post reads в месяц. Владелец выбрал **twitterapi.io**: ~$15 на 5k и ~$55 на 20k участников (с запасом ×2) против ~$145 / ~$580 у X API. Риск ToS и надёжности — `docs_drafts/airdrop/README.md` п. 3.
6. ✅ **Санкционная проверка.** Chainalysis free REST API: бесплатный ключ, OFAC/EU/UN, 5,000 запросов за 5 минут, принимает Solana-адреса; oracle устарел и на Solana не был; кешировать данные нельзя. Плюс локальный список OFAC SDN (4 Solana-адреса) как запасной слой, fail-closed.
7. ⚠️ **Helius `funded-by`.** 404 — кошелёк без входящего SOL, создан без перевода SOL или создан до запуска функции (по документации). Тратятся ли кредиты на 404 — неизвестно. Доля 404 на нашей аудитории всё ещё **замеряется на первых 1,000 кошельках**; фолбэк E1 и «404 = возраст 0 без штрафа» записаны.
8. ✅ **Пороги телеметрии** — стартовые значения записаны (`MULTI-ACCOUNT.md` п. 4): CV < 0.15, > 90% смен на тике 100 мс, медианная реакция < 120 мс, ≤ 3 значения руля на > 60% выборок, точный хэш на ≥ 2 кошельках, самоподобие > 0.98. Только флаги, 2 недели в тени, затем калибровка по перцентилю людей. Числа — **предложение**, не валидированы на наших данных.
9. ✅ **IP и страна — решено 17.10.2026: Cloudflare** (`pr3_update_plan.md` шаг 4g). Прокси Cloudflare (Free), Full (strict) с Origin CA, nginx real_ip из диапазонов Cloudflare (`CF-Connecting-IP`, автообновление), origin закрыт для всех, кроме Cloudflare; страна — `CF-IPCountry`, регион/штат — `cf-region-code` (Managed Transform, есть на Free), фолбэк ipinfo; WAF блокирует санкционные страны и UK/ЕС, регионы и штаты — сервер (`451`), KYC — при выплате. Хэш IP — от `CF-Connecting-IP`.
9а. ✅ **Cloudflare — решено 17.10.2026:** план Free (регионы и штаты проверяет сервер); Turnstile только на привязках аирдропа и реферала, `turnstile_enabled = 0` по умолчанию; origin закрыт фаерволом для диапазонов Cloudflare (без Tunnel); сертификат Cloudflare Origin CA вместо Let's Encrypt; Bot Fight Mode выключен до теста на staging.
