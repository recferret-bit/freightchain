## Глоссарий
- **1h** — часовая поездка, единственная рейтинговая и пуловая.
- **Тренировочная поездка (training)** — `tier = free` (уровни EASY/MEDIUM/HARD: `free-1c`, `free-2c`, `free-3c`; замороженный HARD `free-3b` и старые `free-*`), гостевой офлайн `free-g` и `POST /api/auth/guest`, любая с `tutorial` / `assist`. Без рейтинга, TEN4, мини-игр и реплеев.
- **Devnet-запуск** — первый запуск (Pre-season на devnet, без платных билетов). **Позже** — всё остальное.
- **Пересчёт (re-sim)** — серверная симуляция поездки из сырого ввода с шагом 30 Гц. Источник правды для итога.
- **v1 / v2 / v2.1** — текущий конвейер (сэмплы клиента) / новый (пересчёт) / протокол телеметрии v2.1 (HMAC, потоки).
- **`roadSeed`, `trafficSalt`, `holeSalt`, `mgSalt`** — сид дороги (общий для пула), личные соли трафика, раскладки ям (если попыток > 1) и мини-игр; commit–reveal.
- **`finishS`** — точка финиша в метрах, `Ride.completeDist`.
- **Вердикт** — `verified` / `review` (в схеме сейчас `flagged`) / `rejected`.
- **`RideResult`** — строка статистики поездки в схеме `stats`.
- **Окна пула** — `opens_at`, `sales_close_at = prep_deadline`, `last_start_at`, `play_close_at = play_deadline`, `validation_until = payout_at`.
- **Реплей** — просмотр завершённой поездки. **Стрим** — реплей + чат + донаты водителю. **Live** — просмотр текущей поездки, запрещён (решение 18).
- **Донат / чаевые (tip)** — перевод SOL зрителя водителю, без влияния на игру. **Эффект** — бывший донат, менявший поездку (удаляется).
- **TEN4** — тикер монеты (в main после мержа PR #3). Имя маршрутов, таблиц и `HONK_PROGRAM_ID` остаётся HONK. **HONK** как глагол — строка в чате; сжигание в чат — косметика.
- **Пледж** — SOL зрителя «за км» на билетной поездке (программа `pledge.rs`).
- **Mock RPC** — сервис `mock-rpc` в compose e2e, заменяющий Solana JSON-RPC.
- **Блок 1 / блок 2** — e2e PR #5 без цепочки / с локальным валидатором. **E1M** — блок 1 с mock RPC.
- **MUST / MUST NOT / SHOULD / MAY** — обязательно / запрещено / желательно / допустимо.
