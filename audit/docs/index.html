Source Security Review

Authorized inspection of supplied source, configuration, dependency metadata and existing test coverage. Persistent ACP sessions connect Claude, Codex, Grok and AGY to a restricted Docker MCP bridge.

WorkflowToolsSessionsEvidence

Enforced workflow: source_security_review_v1. Reviewers inspect source, recommend fixes and may run catalogued existing tests only after verified network disconnection.

No arbitrary command interface, new test code, PoC generation, deployed-service probes or transactions. Provider policy failures remain explicit; the coordinator does not change models or retry refusals.

Source to validated report
  1. Capture source bytes, omissions, hashes and existing test entry points.
  2. Run trusted static scanners and the lead harness. Preparation skips target builds, installs, lifecycle scripts, tests and active service scans.
  3. Remove proxy access and verify network disconnection before reviewer handoff.
  4. Inspect source and run fixed existing tests when their dependencies are available. Failed or unavailable checks remain coverage limits.
  5. Validate canonical submissions, collect peer verdicts, adjudicate and render reports. Completion or cancellation removes owned resources; Docker availability is required to verify cleanup.

Fixed test commands: npm --offline --ignore-scripts run test, cargo test --locked --offline or bash --noprofile --norc ./test.sh. The npm test runs with pre/post hooks suppressed. Each invocation verifies the network and entry-point manifest hash, then has a 90-second process-group limit. Missing dependencies are not installed.

Long sessions and recovery

Reviewer reasoning and the held container have no elapsed-time deadline. A heartbeat every 30 seconds records activity. One unexpected transport loss may reload the exact session; cancellation retains evidence and session state. Heartbeats cannot override provider limits.

--resume-from requires matching workflow, source, models, reviewers and assignments. Older adversarial sessions cannot resume into this workflow. Authentication stays with the official host CLIs; no host credentials enter Docker. The CLIs themselves remain trusted host processes.

Evidence and completeness

Findings require source analysis, validation evidence and limits, relative file:line citations, impact and a recommended fix. Controls require review evidence. Canonical MCP commits supply reports; terminal prose does not.

Missing, failed or invalid output remains INCOMPLETE, including a reviewer that submits and then exits unsuccessfully. Zero findings alone is not a clean audit. Scores describe model agreement and peer verdicts rather than independent proof.

check-agents --live qualifies access, saved-session recovery and submission using an inert fixture. It does not establish security coverage or resolve a provider policy refusal.
